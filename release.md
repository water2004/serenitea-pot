Server-side personal Serenitea Pots for Minecraft 26.2 Fabric servers.

- Preserves isolated player data, positions, Creative mode, and flight across repeated entries.
- Supports optional WorldEdit, Axiom, and Worldthreader integrations.
- Includes per-pot performance budgets, automatic freezing, and operator controls.

Requires Fabric Loader 0.19.3+, Fabric API 0.158.0+26.2, Fabric Language Kotlin, and Java 25. Clients do not need this mod installed.
